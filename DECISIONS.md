# Technical & Design Decisions

- **3D Engine**: Pinned Three.js `0.170.0` via jsDelivr ES module import map; zero build step so static files deploy directly to GitHub Pages.
- **Physics**: `@dimforge/rapier3d-compat@0.19.3` WASM via jsDelivr; fixed 60 Hz simulation step (`1/60s`) with transform interpolation and decoupled render loop.
- **Renderer Defaults**: `antialias: false`, pixel ratio capped by user resolution scale (`0.85` default), single directional shadow map (`1024–2048`) over tightened `40×40m` player area (`near 6, far 68`), hemisphere light, opt-in `castShadow` only on hero architecture/vehicles/ground combatants.
- **Triangle Budget**: `renderer.info.autoReset = false`, manual reset/read per frame; hard cap `< 500,000` tris/frame enforced via selective shadow casting, tight prop LOD culling, and automatic quality scaling (`~195k–419k` observed).
- **Village & Verticality**: Paved asphalt street + curbs + sidewalks + overhead wires + dense CC0 urban/military props; 4 enterable 2-story houses + 2 single-story houses + complete enterable **5-Story Apartment Tower** with dual-lane switchback inclined-ramp stair colliders (`55°` max climb angle, `0.42m` autostep) and rooftop terrace.
- **Mobile Controls & Gyro**: Global capture-phase tap handler requests fullscreen + landscape lock on any click/tap; unobstructed idle thumbstick above bottom edge; high touch sensitivity (`0.5–6.0`, default `2.2`) + gimbal-free quaternion-delta landscape Gyroscope (`0.2–6.0`, default `2.2`); custom amber/bone tactical SVG HUD icons with zero keyboard emojis.
- **Enemy AI & Animations**: 4 distinct rigged combat classes with internet CC0 combat clip sets (`idle`, `aim`, `walk`, `run`, `shoot`, `hit`, `death`), static baked weapons attached at `1:100` `WristR` bone space, Rapier `CharacterController` preventing wall clipping, `2.2m` separation spacing, and 3D multi-floor A* pathfinding.
- **Paths & Caching**: Strictly relative paths (`./src/...`, `./assets/...`), Cache Storage API (`ashes-of-vale-assets-v2`) + `assets-manifest.json` real-byte progress loader.
- **Total Download Size**: `7.28 MB` across `68` manifest files (`Models 4.95 MB, Textures 2.00 MB, Audio 0.15 MB, Code 0.18 MB`; `7.32 MB` total repo size vs `60 MB` budget).
