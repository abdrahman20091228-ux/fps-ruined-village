# Technical & Design Decisions

- **3D Engine**: Pinned Three.js `0.170.0` via jsDelivr ES module import map; zero build step so static files deploy directly to GitHub Pages.
- **Physics**: `@dimforge/rapier3d-compat@0.19.3` WASM via jsDelivr; fixed 60 Hz simulation step (`1/60s`) with transform interpolation and decoupled render loop.
- **V5 Mobile Renderer & Bounce Lighting**: Direct ACESFilmic backbuffer rendering with clamped DPR (`<= 1.35 * resolutionScale`, default `0.75`), `MeshLambertMaterial` conversion across enemies/architecture, tightened shadow frustum (`d = 16`, `far = 56`, `shadowInterval` 1–3), interior shadow-cast exclusion, and balanced overcast hemisphere/ambient bounce (`0xc2d5e8 / 0x7c8678`, `ambient 0.36`, `sun 1.05`) keeping outdoor frames crisp while lighting indoor stairwells (`< 390k` tris vs `500k` cap).
- **Triangle & Asset Budgets**: `renderer.info.autoReset = false`, manual reset/read per frame; hard cap `< 500,000` tris/frame with automatic LOD scaling and tiered pine conifer LOD1 crowns; Meshopt-compressed GLBs across all models.
- **V5 Rigid Viewmodels & Cache Busting**: *TinyStrike* GLBs (`m4.glb` + attached `holo.glb` EOTech optic, `akm.glb`, rigid unskinned `pistol.glb` so mobile WebGL vertex skinning never hides sidearms) paired with `ashes-of-vale-assets-v5` cache invalidation to purge stale cached assets.
- **V5 Clean Tactical Soldiers & Combat Balance**: 4 Quaternius CC0 tactical soldiers (`enemy_fighter`, `enemy_swat`, `enemy_soldier`, `enemy_militia`) holding properly scaled `world_m4`/`world_akm`/`world_pistol` weapons (`invScale * 0.78`), native `Rifle_*`/`Pistol_*`/`Hit_*`/`Death01` clips, directional damage chevrons, spawn checkpoint cover, and fair `recruit`/`regular` spread & gunfire hearing ranges.
- **V5 European Mossy Woodland Village**: Overcast mossy pine woodland village replacing desert terrain, featuring custom tileable cobblestone street, weathered European plaster, pitched slate roofs, boulders (`rock.glb`), grass tufts (`grass.glb`), 3-tier pine forest, inward-swinging `DoorSystem` house doors, and a 5-story enterable apartment tower with widened stairwell daylight windows (`2.6m`).
- **Low-Latency Controls, Audio & Pickups**: MEMS gyroscope deadzone + exponential smoothing, per-frame `consumeLook()`, drag-enabled Fire/ADS buttons, HUD Button Customizer (`#hud-editor-overlay`), `HRTF` 3D audio with floor-aware indoor reverb (`INDOORS · F1..F5` / `ROOFTOP`), 7 walkable Medkits, and 5 Ammo Crates resetting cleanly on restart.
- **Total Download Size**: `4.89 MB` across `66` manifest files (`Models 3.10 MB, Textures 1.42 MB, Audio 0.15 MB, Code 0.22 MB`; `4.93 MB` total repo size across `76` files vs `60 MB` budget).
