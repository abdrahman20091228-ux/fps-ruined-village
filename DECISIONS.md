# Technical & Design Decisions

- **3D Engine**: Pinned Three.js `0.170.0` via jsDelivr ES module import map; zero build step so static files deploy directly to GitHub Pages.
- **Physics**: `@dimforge/rapier3d-compat@0.19.3` WASM via jsDelivr; fixed 60 Hz simulation step (`1/60s`) with transform interpolation and decoupled render loop. Fixed `_addStaircase` right-handed `Euler` ramp slope sign (`rx = dz < 0 ? slope : -slope`) so every house & 5-story tower stairwell ascends smoothly.
- **V6 Mobile Renderer & Strict Triangle Budget**: Direct ACESFilmic backbuffer rendering with clamped DPR, `MeshLambertMaterial` conversion across architecture/instanced props, tightened quality triangle targets (`155k` medium preset vs `500k` hard cap), `dead_tree1_lod.glb` / `dead_tree2_lod.glb` matched conifer LODs, landmark-preserving tower LOD distances (`82 / 108`), `ensureFloatAttributes` normalization before `InstancedMesh` matrix transforms, and `skyDome` (`radius 64`) paired with `camera.far >= 72`.
- **V6 Skinned Weapons, Holo Clear-Sight & Cache Busting**: *TinyStrike* GLBs (`m4.glb` via `SkeletonUtils.clone` with folded flip-up iron-sight bones so `holo.glb` EOTech reticle is unobstructed, `akm.glb` with lifted steel/wood shading & glowing tritium sights, rigid `pistol.glb`) paired with `ashes-of-vale-assets-v6` cache invalidation.
- **V6 Controls, PUBG Sprint Lock & Gyroscope Smoothing**: Isolated `#btn-fire` touch tracking (`bindHoldOnly`) so sliding a thumb on Fire never rotates aim while keeping `#btn-ads` thumb-drag active; PUBG-style upper joystick Sprint-Lock latch (`_sprintLocked`) canceled on crouch/ADS; raw MEMS `rotationRate` 1-pole EMA low-pass (`tau = 16ms`) eliminating stepped gyro layers.
- **V6 Single-Shot Audio & Player Foley**: Re-authored `akm_fire.ogg`, `m4_fire.ogg`, and `pistol_fire.ogg` as clean single-shot transients (removing baked burst loops), added `jump.ogg`, `land.ogg`, `player_hurt.ogg`, `bullet_whiz.ogg`, and `weapon_switch.ogg`, and retuned `HRTF` 3D spatialization + floor-aware indoor reverb (`INDOORS · F1..F5` / `ROOFTOP`).
- **Total Download Size**: `5.05 MB` across `73` manifest files (`Models 3.23 MB, Textures 1.42 MB, Audio 0.15 MB, Code 0.24 MB`; `5.09 MB` total repo size across `83` files vs `60.00 MB` budget).
