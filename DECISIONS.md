# Technical & Design Decisions

- **3D Engine**: Pinned Three.js `0.170.0` via jsDelivr ES module import map; zero build step so static files deploy directly to GitHub Pages.
- **Physics**: `@dimforge/rapier3d-compat@0.19.3` WASM via jsDelivr; fixed 60 Hz simulation step (`1/60s`) with transform interpolation and decoupled render loop.
- **V4 Mobile Renderer & Shadow Throttling**: Direct ACESFilmic backbuffer rendering with clamped DPR (`<= 1.25 * resolutionScale`, default `0.75`), `MeshLambertMaterial` conversion across enemies/architecture, `castShadow = false` on skinned meshes/props, and throttled `sunLight` shadow map refresh (`every 2–3 frames`) keeping frames well under `210k` tris (vs `500k` cap).
- **Triangle & Asset Budgets**: `renderer.info.autoReset = false`, manual reset/read per frame; hard cap `< 500,000` tris/frame with automatic LOD scaling; Meshopt-compressed GLBs across all models.
- **V4 Low-Poly Weapons & Bullet Aesthetics**: *TinyStrike* low-poly GLBs (`m4.glb` `1,495` tris, `akm.glb` `1,344` tris, `pistol.glb` `1,318` tris; `22–26 KB`) paired with gloved tactical arms, aligned EOTech Holo / iron / tritium sights, shell casing ejection, and crisp thin translucent bullet streaks (`width 0.014m`) replacing chunky tracers.
- **V4 Animated Tactical Soldiers & Smooth Death**: 4 gear/camo tactical soldier variants sharing real `Rifle_*`, `Pistol_*`, `Hit_Chest`, `Hit_Head`, and `Death01` animation clips without per-frame CPU bone `updateMatrixWorld(true)` IK overhead, plus full-duration grounded `Death01` collapse (`deathFreezeAt`) and directional damage chevrons.
- **V4 World Colliders & Clean Prop Layout**: Full Rapier static colliders on all West/East/South/North perimeter walls, courtyard brick/concrete walls, telegraph poles, slim street lamp trunks, tyres, bushes, garage shutters, rooftop tank, and properly yaw-oriented closed `DoorSystem` colliders; zero intersecting street wrecks/lamps/shutters.
- **V4 Opening Drone Intro & Low-Latency Smooth Controls**: 3.4s quadratic Bezier recon drone fly-in with `REC` HUD and instant `SKIP` button; MEMS gyroscope deadzone (`0.00035`) + low-pass exponential filter + per-frame `consumeLook()` for zero-jitter smooth gyro (`default 1.0x`, touch `1.6x`) and zero input lag across Fire/ADS thumb-drag aiming and HUD Customizer.
- **Wide Stereo 3D Audio & Vertical Village**: `HRTF` 3D audio, stereo indoor reverb, outdoor slapback echoes, 6 ruined houses, enterable 5-story apartment tower, and 7 walkable medkits (`+35 HP`).
- **Total Download Size**: `6.66 MB` across `63` manifest files (`Models 4.38 MB, Textures 1.93 MB, Audio 0.15 MB, Code 0.20 MB`; `6.70 MB` total repo size across `73` files vs `60 MB` budget).
